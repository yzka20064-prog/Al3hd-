# مرآة الأكاذيب الذكية | Smart Lie Detector Mirror

تجربة تفاعلية ترفيهية لبوثات المعارض بواجهة عربية بملء الشاشة وطابع سايبربانك. يجيب الزائر عن 5 أسئلة أمام الكاميرا، ويحلل التطبيق حركة وجهه ونبرة صوته، ثم يعرض **«مؤشر التوتر»** بحجم ضخم في منتصف الشاشة مع مؤثرات صوتية.

> **English:** A fullscreen Arabic-UI booth experience (PySide6). Visitors answer 5 random questions in front of a webcam; OpenCV + MediaPipe FaceMesh track facial motion and the microphone is analyzed for pitch/volume variation. The result is a fun "tension index". **Entertainment only. It does not detect lies.**

## تنبيه مهم

هذا المشروع **ليس جهاز كشف كذب**. لا يمكن استنتاج الكذب أو الصدق بشكل موثوق من حركة الوجه أو الصوت، والمؤشر يقيس فقط ابتعاد الحركة والنبرة عن الحالة الطبيعية للشخص. لا تستخدمه في التوظيف أو الأمن أو التحقيقات أو الحكم على الأشخاص.

## المميزات

- ملء الشاشة بهوامش قليلة ليناسب الشاشات الكبيرة (`F11` للتبديل).
- 5 أسئلة لكل زائر، تُسحب من `questions.txt` بدون تكرار حتى تُستخدم كل الأسئلة.
- جولات متتالية: يظهر السؤال، يضغط الزائر «ابدأ الفحص»، ثم فحص الكاميرا والصوت 4 ثوانٍ.
- شاشة «تحليل البيانات» بعد كل جولة (أطول بعد الجولة الأخيرة).
- نتيجة ضخمة في المنتصف بعدّاد تصاعدي وحكم بالعامية، ثم عودة تلقائية للبداية بعد 30 ثانية.
- مؤثرات صوتية تُولَّد برمجياً بدون ملفات صوت.
- معايرة بضغطة `C` لتناسب الكاميرا والميكروفون والإضاءة في مكان العرض.
- المعالجة محلية بالكامل: لا يُحفظ فيديو ولا صوت.

## المتطلبات

- Windows 10 أو 11
- Python **3.11 أو 3.12** (MediaPipe لا يدعم 3.13 بعد)
- كاميرا، وميكروفون (اختياري؛ بدونه يُحسب المؤشر من الوجه فقط)
- اتصال إنترنت عند التثبيت الأول

## التثبيت والتشغيل

```bat
install_windows.bat   :: مرة واحدة: ينشئ .venv ويثبّت المكتبات
run_windows.bat       :: تشغيل التطبيق
```

أو يدوياً:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## طريقة الاستخدام

1. شغّل التطبيق واسمح بالوصول للكاميرا والميكروفون.
2. **(مرة عند الإعداد)** قف أمام الكاميرا واضغط `C` وتحدث بشكل طبيعي 4 ثوانٍ لمعايرة المؤشر.
3. اضغط «ابدأ التجربة»، ثم في كل جولة اقرأ السؤال واضغط «ابدأ الفحص» وأجب بصوت واضح.
4. بعد الجولة الخامسة تظهر النتيجة.

| المفتاح | الوظيفة |
|---|---|
| `C` | معايرة الحركة والصوت |
| `D` | عرض القيم الحية (للضبط) |
| `F11` / `Esc` | تبديل ملء الشاشة / الخروج منه |
| `Space` / `Enter` | الزر الرئيسي |

## كيف يُحسب مؤشر التوتر

**الوجه:** أول إطار في الفحص يُحفظ كمرجع (Baseline) لنقاط الشفاه والعينين والأنف والحاجبين والرأس. خلال 4 ثوانٍ تُحسب سرعة الحركة بين الإطارات، والانحراف المعياري لحركة النقاط، والانحراف عن المرجع.

**الصوت:** يُحلَّل تذبذب طبقة الصوت (بالنصف-تون)، وتذبذب الشدة، ونسبة الوقفات داخل الإجابة. إن لم يُسمع كلام يُحسب المؤشر من الوجه فقط.

**الدمج:** الوجه 60% والصوت 40% في «نسبة نشاط» تساوي 1.0 عند الحالة الطبيعية. الابتعاد عنها نحو الجمود/الرتابة أو نحو الحركة والتذبذب الشديد يرفع المؤشر من 8% حتى 97%. النتيجة النهائية = نصف متوسط الجولات + نصف أعلى جولة.

### المعايرة

القيم المرجعية الافتراضية تقديرية ولا تناسب كل جهاز. اضغط `C` في مكان العرض لحفظ مرجعك في `calibration.json` (أرقام فقط). أعد المعايرة عند تغيير الكاميرا أو الميكروفون أو الإضاءة، أو احذف الملف للعودة للقيم الافتراضية.

## التخصيص

**الأسئلة:** عدّل `questions.txt` (سؤال في كل سطر، والسطر الذي يبدأ بـ `#` يُتجاهل، ترميز UTF-8). يُفضّل 15 سؤالاً أو أكثر لتقليل التكرار.

**الثوابت** في أعلى `main.py`:

| الثابت | الوصف |
|---|---|
| `ROUNDS` | عدد الأسئلة لكل زائر (5) |
| `SCAN_SECONDS` | مدة الفحص (4 ثوانٍ) |
| `ROUND_ANALYSIS_SECONDS` / `FINAL_ANALYSIS_SECONDS` | مدة شاشة التحليل |
| `AUTO_RESET_SECONDS` | العودة التلقائية بعد النتيجة |
| `FROZEN_STRETCH` | حساسية الجمود (الأصغر = يرفع المؤشر أسرع) |
| `MIX`, `V_MIX`, `FACE_W`, `VOICE_W` | أوزان دمج مؤشرات الوجه والصوت |
| `PCT_FLOOR` / `PCT_CEIL` | أدنى وأعلى قيمة للمؤشر |

**الشعار:** استبدل `assets/logo.png`.

## استكشاف الأخطاء

- **الكاميرا سوداء:** أغلق التطبيقات الأخرى التي تستخدمها، وتأكد من السماح لتطبيقات سطح المكتب في Settings > Privacy & security > Camera.
- **الميكروفون غير متاح:** تحقق من Settings > Privacy & security > Microphone وجهاز الإدخال الافتراضي.
- **«لم يتم رصد وجهك»:** حسّن الإضاءة وقف أمام الكاميرا؛ تُعاد الجولة دون احتسابها.
- **النتائج دائماً عالية أو منخفضة:** أعد المعايرة بالضغط على `C`، واستخدم `D` لمراقبة القيم.
- **فشل التثبيت:** استخدم Python 3.11 أو 3.12 وأعد تشغيل `install_windows.bat`.
